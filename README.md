# Настольные игры — Шахматы, Шашки, Крестики-нолики

Одна папка, четыре HTML-файла. Никаких установок — откройте любой файл в браузере на телефоне или ПК.

## Что внутри

| Файл | Что это |
|------|---------|
| `index.html` | Главное меню — выбор игры |
| `chess.html` | Шахматы — с другом или против бота |
| `checkers.html` | Русские шашки — с другом или против бота |
| `tictactoe.html` | Крестики-нолики — с другом или против бота |

## Общее для всех игр

- Выбор при входе: **с другом** на одном устройстве или **против бота** (выберите сторону/цвет)
- Белые и чёрные фишки — видны на клетках любого цвета
- Удобное управление на телефоне и ПК (крупные клетки, тап/клик, адаптив под экран)
- Анимации: появление экранов, пульсация выбранной клетки, появление фишек/знаков, подсветка взятия
- История ходов, подсветка последнего хода, координаты доски
- Кнопки «Новая игра» и «В меню»

## По играм

**Шахматы** — проверка законности хода каждой фигуры, шах, мат, пат, превращение пешки.
**Шашки** — только тёмные клетки, взятие обязательное, дамки, múltiвзятие.
**Крестики-нолики** — три в ряд, бот умеет выигрывать и блокировать.

Работает офлайн сразу после открытия `index.html`.
